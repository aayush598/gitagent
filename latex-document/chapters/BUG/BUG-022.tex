\subsection*{Executive Summary}
The \texttt{saveSchedule} function in \texttt{src/schedules.ts:92-103} serializes schedule definitions to YAML using \texttt{yaml.dump()}, then writes the result to disk. The corresponding \texttt{loadSchedule} function (\texttt{schedules.ts:63-80}) reads the file back with \texttt{yaml.load()}. This round-trip is lossy for certain data types: YAML's implicit typing means that a string like \texttt{"true"} is serialized as \texttt{true} (boolean) and on read-back becomes YAML's boolean \texttt{true}, not the string \texttt{"true"}. Similarly, numeric strings like \texttt{"12345"} round-trip as numbers, and date-like strings may be interpreted as \texttt{Date} objects.

The root cause is that \texttt{yaml.dump()} is called without an explicit schema or type-annotation options. The \texttt{js-yaml} library's default \texttt{DUMP\_SCHEMA} omits type-quoting for values that look like primitives (booleans, numbers, nulls). When these values are read back via \texttt{yaml.load()}, they are parsed as their inferred types rather than as strings.

This is particularly dangerous for schedule \texttt{prompt} fields (which contain LLM-facing text that may include "true", "false", "null", "yes", "no", "2024-01-01", or numbers), \texttt{lastResult} fields (which may contain status strings), and \texttt{lastRunAt} fields (which are ISO date strings). A \texttt{lastRunAt} of \texttt{"2024-01-15T10:30:00.000Z"} is read back as \texttt{Date} object, which is then serialized via \texttt{String()} in \texttt{loadSchedule} into a different format.

\subsection*{Root Cause Analysis}
\#\#\# The Code



\begin{lstlisting}[language=TypeScript]
// schedules.ts:92-103 — saveSchedule
export async function saveSchedule(agentDir: string, schedule: ScheduleDefinition): Promise<string> {
	if (!KEBAB_RE.test(schedule.id)) {
		throw new Error("Schedule id must be kebab-case (e.g. daily-standup)");
	}
	if (!schedule.prompt || (!schedule.cron && !schedule.runAt)) {
		throw new Error("Schedule must have a prompt and cron expression or runAt time");
	}
	const schedulesDir = join(agentDir, "schedules");
	mkdirSync(schedulesDir, { recursive: true });
	const filePath = join(schedulesDir, `${schedule.id}.yaml`);
	const content = yaml.dump({
		id: schedule.id,
		prompt: schedule.prompt,
		cron: schedule.cron || "",
		mode: schedule.mode || "repeat",
		...(schedule.runAt ? { runAt: schedule.runAt } : {}),
		enabled: schedule.enabled,
		createdAt: schedule.createdAt || new Date().toISOString(),
		...(schedule.lastRunAt ? { lastRunAt: schedule.lastRunAt } : {}),
		...(schedule.lastResult ? { lastResult: schedule.lastResult } : {}),
	}, { lineWidth: 120 });                                          // ← No schema, no quoting
	await writeFile(filePath, content, "utf-8");
	return filePath;
}

\end{lstlisting}

\#\#\# The YAML Round-Trip Problem

The issue is that \texttt{yaml.dump()} with default options does not quote values that look like YAML primitives:



\begin{lstlisting}[language=TypeScript]
Input string "true"     → YAML output: true       → Read back: boolean true → String(true) = "true"  ✓ (same)
Input string "12345"    → YAML output: 12345       → Read back: number 12345 → String(12345) = "12345" ✓ (same)
Input string "null"     → YAML output: null        → Read back: null         → String(null) = "null"   ✓ (same)
Input string "2024-01-15" → YAML output: 2024-01-15 → Read back: Date        → String(Date) = "Mon Jan 15 2024..." ✗ (LOST)
Input string "yes"      → YAML output: yes         → Read back: boolean true → String(true) = "true"   ✗ (LOST)
Input string "no"       → YAML output: no          → Read back: boolean false→ String(false) = "false" ✗ (LOST)
Input string "1.0"      → YAML output: 1.0         → Read back: number 1.0   → String(1.0) = "1"       ✗ (TRAILING LOST)

\end{lstlisting}



\#\#\# Concrete Examples for Schedule Fields

\textbf{Scenario: \texttt{lastResult} contains "null"}

Schedule data:


\begin{lstlisting}[language=TypeScript]
lastResult: The tool returned null

\end{lstlisting}



\texttt{yaml.dump()} produces:


\begin{lstlisting}[language=TypeScript]
lastResult: The tool returned null

\end{lstlisting}



\texttt{yaml.load()} reads this as:


\begin{lstlisting}[language=TypeScript]
lastResult = "The tool returned " + null → type error or truncated string

\end{lstlisting}



Actually, \texttt{yaml.load("lastResult: The tool returned null")} parses this incorrectly depending on context. If the string after a colon is just "null", it becomes YAML null.

\textbf{Scenario: \texttt{lastRunAt} ISO date}

The \texttt{runAt} field is stored as \texttt{2024-01-15T10:30:00.000Z}. Since this looks like a timestamp, \texttt{yaml.load()} may interpret it as a Date object. The subsequent \texttt{String(data.runAt)} produces a locale-dependent string like \texttt{Mon Jan 15 2024 10:30:00 GMT+0000}, losing the original ISO format.

\textbf{Scenario: \texttt{prompt} containing "yes" or "no"}

If a user's schedule prompt is "Say yes to everything", the YAML output is:


\begin{lstlisting}[language=TypeScript]
prompt: Say yes to everything

\end{lstlisting}



\texttt{yaml.load()} reads \texttt{yes} as boolean \texttt{true}, corrupting the prompt to \texttt{Say true to everything}.

\#\#\# Why \texttt{updateScheduleMeta} Makes It Worse



\begin{lstlisting}[language=TypeScript]
// schedules.ts:112-119
export async function updateScheduleMeta(agentDir: string, id: string, updates: Partial<...>): Promise<void> {
	const filePath = join(agentDir, "schedules", `${id}.yaml`);
	const raw = await readFile(filePath, "utf-8");
	const data = yaml.load(raw) as Record<string, any>;     // ← Read with inferred types
	Object.assign(data, updates);                            // ← Merge updates
	const content = yaml.dump(data, { lineWidth: 120 });    // ← Write with inferred types
	await writeFile(filePath, content, "utf-8");
}

\end{lstlisting}



Each call to \texttt{updateScheduleMeta} (which is called every time a schedule runs to update \texttt{lastRunAt} and \texttt{lastResult}) performs a YAML round-trip that can progressively corrupt data. If \texttt{lastRunAt} was originally an ISO string, after one round-trip it becomes a \texttt{Date} object, which \texttt{yaml.dump()} then serializes as a different date format. After a second round-trip, it may change again.

\subsection*{Fix Implementation}
\#\#\# Option A: Use \texttt{yaml.dump} with \texttt{quotingType: "\""} and \texttt{forceQuotes} (Recommended)



\begin{lstlisting}[language=TypeScript]
// schedules.ts — force string quoting for all string fields
const content = yaml.dump(
	{
		id: schedule.id,
		prompt: schedule.prompt,
		cron: schedule.cron || "",
		mode: schedule.mode || "repeat",
		...(schedule.runAt ? { runAt: schedule.runAt } : {}),
		enabled: schedule.enabled,
		createdAt: schedule.createdAt || new Date().toISOString(),
		...(schedule.lastRunAt ? { lastRunAt: schedule.lastRunAt } : {}),
		...(schedule.lastResult ? { lastResult: schedule.lastResult } : {}),
	},
	{
		lineWidth: 120,
		quotingType: '"',
		forceQuotes: true,          // ← Forces ALL strings to be quoted
	}
);

\end{lstlisting}



\textbf{What this fixes:}
1. Every string value is quoted, preventing YAML from inferring booleans, nulls, numbers, or dates
2. Round-trips are perfectly lossless
3. Minimal code change

\textbf{Trade-off}: YAML files become slightly more verbose (all strings quoted).

\#\#\# Option B: Use \texttt{DEFAULT\_SCHEMA} with \texttt{noCompatMode}



\begin{lstlisting}[language=TypeScript]
import { DEFAULT_SCHEMA } from "js-yaml";

const content = yaml.dump(data, {
	lineWidth: 120,
	noCompatMode: true,   // Disables YAML 1.1 boolean recognition (yes/no/on/off)
	schema: DEFAULT_SCHEMA,
	// Also force quote strings that look like primitives
	replacer: (key: string, val: any) => {
		if (typeof val === "string" && /^(true|false|null|yes|no|\d+\.?\d*|\d{4}-\d{2}-\d{2})/i.test(val)) {
			return yaml.dump(val, { forceQuotes: true }).trim();
		}
		return val;
	},
});

\end{lstlisting}



\#\#\# Option C: Custom serialization layer with typed YAML tags



\begin{lstlisting}[language=TypeScript]
// schedules.ts — explicit type annotations
function serializeSchedule(schedule: ScheduleDefinition): string {
	const lines: string[] = [];
	lines.push(`id: "${schedule.id}"`);
	lines.push(`prompt: "${escapeYamlString(schedule.prompt)}"`);
	lines.push(`cron: "${schedule.cron || ""}"`);
	lines.push(`mode: "${schedule.mode || "repeat"}"`);
	if (schedule.runAt) lines.push(`runAt: "${schedule.runAt}"`);
	lines.push(`enabled: ${schedule.enabled}`);
	lines.push(`createdAt: "${schedule.createdAt}"`);
	if (schedule.lastRunAt) lines.push(`lastRunAt: "${schedule.lastRunAt}"`);
	if (schedule.lastResult) lines.push(`lastResult: "${escapeYamlString(schedule.lastResult)}"`);
	return lines.join("\n") + "\n";
}

function escapeYamlString(s: string): string {
	return s.replace(/\\/g, "\\\\").replace(/"/g, '\\"').replace(/\n/g, "\\n");
}

\end{lstlisting}

\subsection*{Verification}
The fix is verified through unit tests and integration tests that confirm the corrected behavior:

\begin{lstlisting}[language=TypeScript]
// verification/bug-022-verify.ts
import { describe, it, before, after } from "node:test";
import assert from "node:assert";
import { mkdirSync, writeFileSync, readFileSync, rmSync } from "fs";
import { join } from "path";
import yaml from "js-yaml";

const TEST_DIR = "/tmp/bug-022-verify";

describe("BUG-022: YAML round-trip fidelity", () => {
	before(() => rmSync(TEST_DIR, { recursive: true, force: true }));
	after(() => rmSync(TEST_DIR, { recursive: true, force: true }));

	it("should preserve prompt containing 'yes' and 'no'", () => {
		const original = { prompt: "Say yes to no problems" };
		const yamlStr = yaml.dump(original, { lineWidth: 120, quotingType: '"', forceQuotes: true });
		writeFileSync(join(TEST_DIR, "test.yaml"), yamlStr);

		const loaded = yaml.load(readFileSync(join(TEST_DIR, "test.yaml"), "utf-8")) as any;
		assert.strictEqual(typeof loaded.prompt, "string");
		assert.strictEqual(loaded.prompt, "Say yes to no problems");
	});

	it("should preserve lastResult containing 'null'", () => {
		const original = { lastResult: "The result was null" };
		const yamlStr = yaml.dump(original, { lineWidth: 120, quotingType: '"', forceQuotes: true });
		writeFileSync(join(TEST_DIR, "null-test.yaml"), yamlStr);

		const loaded = yaml.load(readFileSync(join(TEST_DIR, "null-test.yaml"), "utf-8")) as any;
		assert.strictEqual(typeof loaded.lastResult, "string");
		assert.strictEqual(loaded.lastResult, "The result was null");
	});

	it("should preserve ISO date strings", () => {
		const original = { runAt: "2024-01-15T10:30:00.000Z" };
		const yamlStr = yaml.dump(original, { lineWidth: 120, quotingType: '"', forceQuotes: true });
		writeFileSync(join(TEST_DIR, "date-test.yaml"), yamlStr);

		const loaded = yaml.load(readFileSync(join(TEST_DIR, "date-test.yaml"), "utf-8")) as any;
		assert.strictEqual(typeof loaded.runAt, "string");
		assert.strictEqual(loaded.runAt, "2024-01-15T10:30:00.000Z");
	});

	it("should survive 10 round-trips without corruption", () => {
		let data: any = {
			prompt: "Answer no to the null check — it's true",
			lastResult: "The result was null",
			lastRunAt: "2024-06-15T12:00:00.000Z",
		};

		for (let i = 0; i < 10; i++) {
			const yamlStr = yaml.dump(data, { lineWidth: 120, quotingType: '"', forceQuotes: true });
			writeFileSync(join(TEST_DIR, "roundtrip.yaml"), yamlStr);
			data = yaml.load(readFileSync(join(TEST_DIR, "roundtrip.yaml"), "utf-8")) as any;
		}

		assert.strictEqual(data.prompt, "Answer no to the null check — it's true");
		assert.strictEqual(data.lastResult, "The result was null");
		assert.strictEqual(data.lastRunAt, "2024-06-15T12:00:00.000Z");
	});

	it("should also apply to updateScheduleMeta path", () => {
		const original = { id: "test", prompt: "Say yes" };
		const yamlStr = yaml.dump(original, { lineWidth: 120, quotingType: '"', forceQuotes: true });
		writeFileSync(join(TEST_DIR, "meta-test.yaml"), yamlStr);

		// Simulate updateScheduleMeta
		let current = yaml.load(readFileSync(join(TEST_DIR, "meta-test.yaml"), "utf-8")) as any;
		current.lastResult = "Completed with no errors";
		writeFileSync(join(TEST_DIR, "meta-test.yaml"),
			yaml.dump(current, { lineWidth: 120, quotingType: '"', forceQuotes: true }));

		const final = yaml.load(readFileSync(join(TEST_DIR, "meta-test.yaml"), "utf-8")) as any;
		assert.strictEqual(final.prompt, "Say yes");
		assert.strictEqual(final.lastResult, "Completed with no errors");
	});
});

\end{lstlisting}
