\subsection*{Executive Summary}
The \code{memory} tool's \code{save} action in \srcfile{src/tools/memory.ts} calls \code{execSync("git add ... \&\& git commit ...")}. If two \code{save} calls execute concurrently — from parallel tool invocations or overlapping hook-triggered saves — the git operations interleave. The first commit may include files staged by the second add (and vice versa), leading to commits with incorrect content, wrong messages, or git index corruption.

\subsection*{Root Cause Analysis}
The git operations run without serialization:

\begin{lstlisting}[language=TypeScript]
// BEFORE — concurrent saves interleave git operations
try {
    execSync(`git add "${memoryPath}" && git commit -m "${commitMsg.replace(/"/g, '\\"')}"`, {
        cwd,
        stdio: "pipe",
    });
} catch (err: any) { ... }
\end{lstlisting}

Timeline of a race: Process A writes MEMORY.md with ``foo''; Process B writes MEMORY.md with ``bar''; B's \code{git add} overwrites A's staged content; A's commit says ``save foo'' but actually commits ``bar''; B's commit has nothing to commit.

\subsection*{Fix Implementation}
A \code{GitMutex} serializes all git operations:

\begin{lstlisting}[language=TypeScript]
// AFTER — mutex serializes git operations
class GitMutex {
    private queue: (() => void)[] = [];
    private locked = false;
    async acquire<T>(fn: () => T): Promise<T> {
        await new Promise<void>((resolve) => {
            if (!this.locked) { this.locked = true; resolve(); }
            else { this.queue.push(resolve); }
        });
        try { return fn(); }
        finally {
            if (this.queue.length > 0) { this.queue.shift()!(); }
            else { this.locked = false; }
        }
    }
}
const gitMutex = new GitMutex();

// In save action:
try {
    await gitMutex.acquire(() => {
        execSync(`git add "${memoryPath}" && git commit -m "${commitMsg.replace(/"/g, '\\"')}"`, {
            cwd,
            stdio: "pipe",
        });
    });
} catch (err: any) { ... }
\end{lstlisting}
