\subsection*{Executive Summary}
The GitAgent voice server (\srcfile{src/voice/server.ts}) provides both an HTTP server (for the web UI and REST API) and a WebSocket server (for voice mode real-time communication). The server has a password protection mechanism---but it is opt-in only. If the \texttt{GITCLAW\_PASSWORD} environment variable is not set, the \texttt{isAuthenticated()} function returns \texttt{true} for every request. This means that out of the box with no configuration, the server grants full unauthenticated access to anyone who can reach the port.

The fix requires authentication by default by generating a random 32-character hex password when \texttt{GITCLAW\_PASSWORD} is not set, and binds the server to \texttt{127.0.0.1} (localhost) by default instead of all interfaces. The auto-generated password is printed to the console at startup so the user can log in.

\subsection*{Root Cause Analysis}
The critical vulnerability is in \texttt{isAuthenticated()}:

\begin{lstlisting}[language=TypeScript]
const serverPassword = process.env.GITCLAW_PASSWORD || "";
const serverUsername = process.env.GITCLAW_USERNAME || (serverPassword ? "admin" : "");

function isAuthenticated(req: IncomingMessage): boolean {
    if (!serverPassword) return true; // <-- BYPASS: no password = open access
    const cookie = req.headers.cookie || "";
    const match = cookie.match(new RegExp(`${authCookieName}=([^;]+)`));
    return match?.[1] === generateAuthToken();
}
\end{lstlisting}

When \texttt{GITCLAW\_PASSWORD} is not set, \texttt{serverPassword} is \texttt{""} (falsy), so \texttt{isAuthenticated()} returns \texttt{true} for every request. The server also binds to all interfaces by default (\texttt{httpServer.listen(port)} with no host argument), and sets \texttt{Access-Control-Allow-Origin: *}, allowing cross-origin requests from any website.

\subsection*{Fix Implementation}
The fix makes three changes to \srcfile{src/voice/server.ts}. First, authentication is always required by generating a random password when none is configured:

\begin{lstlisting}[language=TypeScript]
import crypto from "crypto";

const serverPassword = process.env.GITCLAW_PASSWORD ||
    crypto.randomBytes(16).toString("hex");
const serverUsername = process.env.GITCLAW_USERNAME || "admin";
const autoGenerated = !process.env.GITCLAW_PASSWORD;

function isAuthenticated(req: IncomingMessage): boolean {
    const cookie = req.headers.cookie || "";
    const match = cookie.match(new RegExp(`${authCookieName}=([^;]+)`));
    return match?.[1] === generateAuthToken();
}
\end{lstlisting}

The unconditional bypass (\texttt{if (!serverPassword) return true}) is removed. Second, the server binds to localhost only:

\begin{lstlisting}[language=TypeScript]
httpServer.listen(port, "127.0.0.1", () => resolve());
\end{lstlisting}

Third, the startup logs are updated to show the auto-generated password and the localhost-only URL:

\begin{lstlisting}[language=TypeScript]
if (autoGenerated) {
    console.log(dim(\texttt{[voice] Auth: auto-generated password --- use "\${serverPassword}" to log in}));
}
console.log(dim(\texttt{[voice] Auth: user "\${serverUsername}"}));
console.log(dim(\texttt{[voice] Open http://127.0.0.1:\${port} in your browser}));
\end{lstlisting}

The \texttt{crypto} import replaces the previous inline \texttt{require("crypto")} calls, improving both performance and code clarity by importing at module scope.

\subsection*{Affected Files}
\begin{itemize}
    \item \srcfile{src/voice/server.ts} --- Added top-level \texttt{import crypto from "crypto"}, replaced conditional authentication bypass with always-on auth, added auto-generated random password fallback, bound server to \texttt{127.0.0.1} by default, updated startup logging for security visibility, replaced inline \texttt{require("crypto")} with module-level import.
\end{itemize}

\subsection*{Verification}
Verification is performed by starting the server without \texttt{GITCLAW\_PASSWORD} and confirming that the login page is displayed (instead of the application), that the console prints the auto-generated password, and that the server is only reachable on \texttt{127.0.0.1}. With \texttt{GITCLAW\_PASSWORD} set, verification confirms that unauthenticated requests receive the login page and authenticated requests with the correct cookie succeed.

\subsection*{Test File}
\srcfile{verification/sec-008-verify.sh} (manual shell-based test)

Starts the server with and without \texttt{GITCLAW\_PASSWORD}, verifies HTTP status codes and response content to confirm authentication is required by default, and tests localhost-only binding.
