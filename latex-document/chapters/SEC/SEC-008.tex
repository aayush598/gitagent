\subsection*{Executive Summary}
The GitAgent voice server (\srcfile{src/voice/server.ts}) provides both an HTTP server (for the web UI and REST API) and a WebSocket server (for voice mode real-time communication). Originally the server had an opt-in password protection mechanism that was bypassed when \texttt{GITCLAW\_PASSWORD} was not set, granting full unauthenticated access to anyone who could reach the port.

The fix requires authentication by default by generating a random password when \texttt{GITCLAW\_PASSWORD} is not set, binds the server to \texttt{127.0.0.1} (localhost) only, restricts CORS to local origins, adds rate limiting on login attempts, and uses a per-server salt for session token generation.

\subsection*{Root Cause Analysis}
The critical vulnerability was in \texttt{isAuthenticated()} at \srcfile{src/voice/server.ts}:

\begin{lstlisting}[language=TypeScript]
const serverPassword = process.env.GITCLAW_PASSWORD || "";
function isAuthenticated(req: IncomingMessage): boolean {
    if (!serverPassword) return true; // BYPASS: no password = open access
    // ...actual auth check...
}
\end{lstlisting}

When \texttt{GITCLAW\_PASSWORD} was not set, \texttt{serverPassword} was \texttt{""} (falsy), so every request was authenticated. The server also bound to all interfaces by default and set \texttt{Access-Control-Allow-Origin: *}.

\subsection*{Fix Implementation}
The fix applies defense in depth with multiple layers:

\textbf{Always-on authentication}: Authentication is always required by generating a random 32-character hex password when none is configured:

\begin{lstlisting}[language=TypeScript]
const serverPassword = process.env.GITCLAW_PASSWORD ||
    crypto.randomBytes(16).toString("hex");
const serverUsername = process.env.GITCLAW_USERNAME || "admin";
\end{lstlisting}

The unconditional bypass (\texttt{if (!serverPassword) return true}) is removed.

\textbf{Session salt}: A per-server random salt prevents token reuse across restarts:

\begin{lstlisting}[language=TypeScript]
const sessionSalt = crypto.randomBytes(8).toString("hex");
function generateAuthToken(): string {
    return crypto.createHash("sha256")
        .update(\texttt{`\${serverUsername}:\${serverPassword}:\${sessionSalt}`})
        .digest("hex").slice(0, 32);
}
\end{lstlisting}

\textbf{Localhost binding}: The server binds to \texttt{127.0.0.1} only:

\begin{lstlisting}[language=TypeScript]
httpServer.listen(port, "127.0.0.1", () => resolve());
\end{lstlisting}

\textbf{CORS restriction}: Instead of \texttt{Access-Control-Allow-Origin: *}, the server reflects the origin only if it is a local origin:

\begin{lstlisting}[language=TypeScript]
const allowedOrigin = origin && (origin.startsWith("http://localhost")
    || origin.startsWith("http://127.0.0.1")
    || origin.startsWith("http://[::1]"));
if (allowedOrigin && origin) {
    res.setHeader("Access-Control-Allow-Origin", origin);
} else {
    res.setHeader("Access-Control-Allow-Origin", \texttt{`http://127.0.0.1:\${port}`});
}
\end{lstlisting}

\textbf{Rate limiting}: The login endpoint is rate-limited to 5 attempts per second to prevent brute force:

\begin{lstlisting}[language=TypeScript]
function checkLoginRateLimit(): boolean {
    const now = Date.now();
    if (now > loginResetTime) {
        loginAttempts = 0;
        loginResetTime = now + 1000;
    }
    loginAttempts++;
    return loginAttempts <= 5;
}
\end{lstlisting}

\textbf{Password leak prevention}: The auto-generated password prefix is shown instead of the full password:

\begin{lstlisting}[language=TypeScript]
console.log(dim(\texttt{`[voice] Auth: auto-generated password
    (prefix: "\${serverPassword.slice(0, 4)}...")
    --- set GITCLAW\_PASSWORD to use a custom password`}));
\end{lstlisting}

\subsection*{Affected Files}
\begin{itemize}
    \item \srcfile{src/voice/server.ts} --- Added top-level \texttt{import crypto from "crypto"}, replaced conditional auth bypass with always-on auth, added auto-generated random password fallback, per-server session salt, rate limiting on login, CORS origin restriction, bound server to \texttt{127.0.0.1}, fixed password leak in console logs.
    \item \srcfile{test/ws-auth.test.ts} --- Comprehensive unit test suite with 22 tests.
\end{itemize}

\subsection*{Verification}
22 automated tests verify: deterministic token generation, token changes when password/salt changes, valid/invalid cookie auth, timing-safe string comparison, rate limiting (allows 5, blocks 6th, resets after window), and CORS origin validation (allows localhost/127.0.0.1/[::1], rejects external origins).
