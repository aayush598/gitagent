Interpretation

  • Async is faster for a single agent turn (0.24ms difference).
  • Concurrent throughput is 2.17× better with async — operations overlap instead of serializing.
  • Timer responsiveness: SYNC BLOCKS the event loop. With sync, setTimeout callbacks are delayed until the git operation completes.
  • In a real deployment (voice, HTTP, WebSocket), the event loop must stay free. Async eliminates dropped connections and stalled streams.
